# 💼 Sales Package — Polska Auto Leads Engine v3.0.0

## 1) 1-pager (gotowy opis oferty)

**Nazwa:** Polska Auto Leads Engine  
**Typ:** gotowy produkt SaaS (kod + dokumentacja + lokalne demo)  
**Dla kogo:** software house, agencje lead-gen, firmy automotive/services, founderzy kupujący gotowy produkt do dalszego rozwoju.

### Co automatyzuje
- pozyskiwanie leadów i scoring,
- pipeline sprzedażowy i follow-up,
- dashboardy operacyjne i biznesowe,
- backup/recovery oraz moduły bezpieczeństwa,
- panel web + API + dokumentacja Swagger.

### Co otrzymuje kupujący
- pełne repozytorium projektu,
- dokumentację techniczną (`README.md`, `API.md`, `SPEC.md`),
- instrukcję uruchomienia lokalnego (`bash start_all.sh`),
- listę endpointów i modułów,
- checklistę przekazania (poniżej).
